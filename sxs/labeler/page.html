What it is

Marked items

Drag on the screen to mark a button, text, icon or area.
Drag on the screen to draw a box. Click a box to select it, drag it to move it, drag its corner to resize it. Del removes the selected box, Ctrl+S saves, [ and ] go to the previous or next screen. Colours: blue button, green text, purple icon, red badge, orange region. Dashed boxes are drafts the pre-labeller drew: fix them and press Confirm, or remove them. C confirms the selected box. The class menu says which detector class a box is (only boxes with a class train the detector).
