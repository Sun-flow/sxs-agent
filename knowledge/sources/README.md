# Sources

<!-- index: The register of every source tag (S-NN) used in knowledge/, with reliability tier; how sources are fetched -->

> **Summary:** every fact in `knowledge/` ends in a tag. `[R-NNN]` is a rule we observed ourselves (`memory-bank/game/rules/`); `[S-NN]` is an outside source listed below. Trust falls from tier A to tier D; a fact resting only on tier D carries a ❓.
> **Related:** [CONVENTIONS](../CONVENTIONS.md), [provenance.md](provenance.md) (who writes each site, how it gets its information, fetch recipes), [conflicts](../conflicts.md)

## Tiers

| Tier | Meaning |
|---|---|
| A | Seen in our own game or stated by mae: a rule ID |
| B | Experienced players of the live game, or the publisher's own posts |
| C | Community wikis, player blogs, data-style sites; possibly outdated or from another server or region |
| D | SEO and auto-written guide sites: leads only |

## Folders

| Path | Holds |
|---|---|
| `guides/` | Full structured notes of the two player guides mae uploaded (S-01, S-02), every table transcribed |
| `notes/` | Structured notes of whole sites, written in our own words (zeroluck, eog, Loot & Waifus, official site, the Chinese version) |
| `raw/fandom/` | The Fandom wiki as wikitext (CC BY-SA 3.0; `manifest.json` credits each page). Refresh: `python3 scripts/kb_fetch.py fandom` |
| `raw/<other>/` | Working caches of sites with no stated licence. Gitignored: re-create with `python3 scripts/kb_fetch.py <name>` |
| `provenance.md` | The survey of sources: lineage of the game, who writes what, fetch recipes, hosts to allow |
